# ai-tutor — AI 导师学习法 Skill

把你的 AI 编程助手（ZCode / Claude Code 等）变成一位**私人导师**：先摸底、出学习路线、单点教学、复述检验、纠错复验——跑完整个闭环，防止"看懂了 ≠ 学会了"。长课程支持**跨会话学习档案**，随时续学不弃课。

源自 2023 年起网上疯传的"AI 导师学习法"（Mr. Ranedeer AI Tutor、"我想学 Z 但只懂 A"模板、费曼技巧、苏格拉底式提问），并经过两轮**子模型对照实测**校准（见下文），把实测发现的失效点直接写成了硬性规则。

## 四种教学模式

| 模式 | 触发说法 | 定位 |
|---|---|---|
| **A 导师模式**（默认） | "教我X / 我想学X但只懂Y / 帮我制定学习计划" | 全程陪跑：摸底 → 差距分析 → ≤10 步路线 → 单点教学 → 复述闸门 |
| **B 速览模式** | "快速讲下X / 我只要个大概认知" | 30 分钟建全局地图，必须声明覆盖边界与置信度，不可单独用于完整学习 |
| **C 费曼模式** | "考考我 / 检验我懂没懂 / 我给你讲讲X" | 验收关卡：脱稿讲给外行听（不剧透考点）→ 追问/纠错/按锚点打分 → 主动补考没讲到的相邻点 |
| **D 苏格拉底模式** | "别直接告诉我答案 / 引导我自己想通X" | 点穴：反例造矛盾 → 权威锚定 → 完整重述通过即退出，切回主线 |

推荐组合：**B 开局建地图 → A 日常推进 → C 每节验收 → D 专治顽固误解**。

## 特色机制

- **复述闸门**：通过标准 = 无实质错误 + 外行能听懂，缺一不可。不接受"差不多就是那个意思"；复述中夹带新错误则回到完整重述；赶进度可压缩讲解但不可跳过复述。
- **打分锚点（10 分制）**：9~10 能讲给外行+能纠别人的错；7~8 主干对、个别含糊；5~6 需提示才补得全；<5 有实质错误不通过。拒绝客套分。
- **跨会话学习档案**：会话结束自动生成（目标基础 / 路线进度 / 已掌握 / 仍虚的点 / 下次从哪开始）。下次说"继续上次学的X"并贴档案，直接从断点续学，不重新摸底；档案里"未复验"的纠错点会被主动补验收。
- **教学事实置信分级**：有课程材料先读材料、锚定材料教；无材料时对关键公式/版本号/价格提示用户对照官方文档确认。

## 对照实测（2026-10，子模型分饰导师×学习者，5 轮会话 + 故意埋错）

| 维度 | A 导师 | B 速览 | C 费曼 | D 苏格拉底 |
|---|---|---|---|---|
| 基础定制 | 5 | 2 | 3 | 3 |
| 知识质量 | 4 | 3 | 3 | 2 |
| 防假学会 | 5 | 1 | 5 | 4 |
| 纠错能力 | 5 | 3 | 5 | 4 |
| 长期可持续 | 3 | 4 | 3 | 2 |
| **总分** | **22** | **13** | **19** | **15** |

实测中发现的失效点（均已写入 skill 硬性规则）：

1. **纠错不复验 = 新版假学会**——顺手纠正一句就继续赶课，用户产生"被纠正过 ≈ 学会了"的错觉
2. **只检验用户讲到的范围 = 没检验**——没讲到的相邻知识点等于不存在
3. **全程禁言不锚定答案**——学习者带着 90% 正确的理解离场
4. **对什么都要"讲-复述-评估"**——流程税让长课程三天弃学
5. **提示词只决定教学结构**——课程里的特色细节（计费口径、版本陷阱）必须喂材料才教得到
6. **费曼检验剧透考点**——布置任务时列出"要覆盖XX"，用户照提纲背一遍，检验就废了
7. **"差不多"式复述放行**——一句"就是那个意思吧"蒙混过关，等于没有闸门

## 安装

**ZCode：**

```bash
git clone https://github.com/GA1st/ai-tutor ~/.agents/skills/ai-tutor
```

（或放 `~/.zcode/skills/ai-tutor`，同名时该路径优先级更高）

**Claude Code / 其他兼容 Agent Skills 规范的工具：**

```bash
git clone https://github.com/GA1st/ai-tutor ~/.claude/skills/ai-tutor
```

安装后对 AI 说"教我 X"、“我想学 X 但只懂 Y"、“考考我 X"、“继续上次学的 X"即可触发。
